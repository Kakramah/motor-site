# التسليم والاستمرار

قبل العمل في مستودع قائم: حالة الملفات، الفرع، آخر سجل وآخر طلبات دمج؛ لا pull مع تغييرات غير مفهومة ولا حذف عمل شخص آخر. في مشروع جديد: أنشئ المستودع محلياً على فرع codex؛ لا تخترع مستودعاً بعيداً ولا رابط نشر.

المطلوب عند التسليم: README للتشغيل، BRIEF، DESIGN، STORYBOARD حيث يلزم، evidence.json، assets.json، qa.json، سجل تغييرات مختصر، ونتيجة الفاحص. لا تنشر مواصفات البحث الخاصة أو بيانات الأشخاص لمجرد أن ملفات الموقع عامة.

عند وجود مستودع GitHub وإذن دفع: commit محدد، push للفرع، PR إلى الفرع المعتمد. وصف PR: المشكلة، النتيجة، الاختبارات الفعلية، الحدود. صاحب المشروع يدمج ما لم يطلب خلاف ذلك. إرفاق PR بالمحادثة إذا كانت الأداة متاحة.

بعد إذن النشر: انتظر اكتمال المهمة المخصصة للنشر ثم افتح الرابط وتحقق من أصل جديد مميز، تنقل، هاتف، مشاركة. إذا كان رابط المشروع ثابتاً فلا يلزم تبديله في الفهرس؛ حدّث العنوان أو المصغرة عند تغيرهما وفق نطاق الطلب.

لا موافقات مكررة لقراءة أو بناء أُذن به، ولا توقف شكلي بين المراحل. الصلاحيات التي يفرضها نظام الجهاز تُطلب عند الحاجة الحقيقية فقط.
