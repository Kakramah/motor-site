# مكتبة الخصائص حسب الحاجة

| الخاصية | متى تفيد | معيار القبول |
|---|---|---|
| مشهد تمريري | دليل أو علاقة تتكشف | لكل خطوة اختلاف معنوي؛ الهاتف يقرأ الصورة مع النص؛ الرجوع يعمل |
| شبكة علاقات | أطراف وصلات لها مصادر | معنى كل وصلة ومصدرها؛ لوحة تفاصيل؛ بديل نصي؛ لا زخرفة علاقات |
| خط زمني | تسلسل أحداث مؤثر | تاريخ ومصدر ونطاق زمني واضح؛ ترتيب صحيح؛ لا تحريك بلا فائدة |
| بوصلة/تبويبات | تفسير محاور متوازية | تحديث المحتوى وaria-selected؛ أسهم/Home/End؛ محتوى متاح بلا JS |
| مقارنة/ميزان | بدائل أو مسؤوليات | معايير متماثلة وحدود معلنة؛ لا توازن شكلي لأدلة غير متساوية |
| مستند مشروح | فحص دليل بصري | أصل قابل للفتح؛ شرح المنطقة؛ مصدر وتاريخ؛ لا صور وثائق مولدة |
| معرض/عارض صور | تفاصيل تحتاج تكبيراً | اسم ووصف وحقوق؛ Escape؛ إدارة التركيز؛ لا حبس للوحة المفاتيح |
| فهرس بحث | أعمال أو وثائق متعددة | بحث عربي، عدد نتائج محسوب، حالة لا نتائج، رابط مباشر لكل عنصر |
| رسم بيانات | كمية أو مقارنة | مصدر ووحدة ومحاور وبديل جدولي؛ نتائج محسوبة من البيانات |
| نموذج تواصل | مهمة اتصال حقيقية | تحقق المدخلات، إرسال فعلي، نجاح/خطأ، منع التكرار؛ لا أسرار خادم في الصفحة |
| مشاركة | محتوى للنشر | الرابط النهائي الصحيح؛ نسخ مؤكد؛ بديل عند رفض الحافظة |
| طباعة/PDF | تقرير خارج المتصفح | تنسيق طباعة، إظهار كل التبويبات، إزالة Sticky، تفادي قطع العناصر؛ PDF مستقل إذا وُعد بتنزيله |
| أداة حساب/تحويل | قرار أو إنتاج | مدخلات صالحة، خطأ واضح، مخرجات قابلة للتكرار، لا زر بلا فعل |

هيكل المصنع ينفّذ تقدّم القراءة، كشفاً تمريرياً، تبويبات ميسّرة، بحثاً بسيطاً، مقارنة، نسخ رابط، وطباعة. شبكة العلاقات والخرائط والرسوم المتخصصة وصفات تطوير في هذا الدليل، لا ندّعي أنها مكونات جاهزة في المولّد. استخدم المشروع المناسب مرجعاً وكيّفه مع أدلة الموضوع.
