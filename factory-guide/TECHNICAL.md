# التنفيذ القابل للصيانة

الموقع التحريري الثابت يبدأ بـHTML/CSS/JS؛ لا خادم وحزم لمجرد المظهر. الأداة المعقدة أو الحسابات أو البيانات المتغيرة تستخدم إطار المشروع والخادم المناسب بعد توضيح الحاجة. لا تفترض أن GitHub Pages يخزّن نماذج أو يحمي مفاتيح API.

- `lang="ar"` و`dir="rtl"`؛ خصائص CSS المنطقية؛ عزل اللاتيني بـdir/ltr أو bdi.
- نص حقيقي في HTML؛ الصور ليست واجهات مكتملة بديلة عنه. عناصر button للأفعال وa للانتقال.
- الخطوط المحلية وترخيص كل عائلة؛ مقياس مرن للعناوين ومتـن مريح. لا تحميل وزن غير موجود.
- حسنات تدريجية: المحتوى الأساسي ظاهر بلا JS، والفلاتر والتبويبات إضافات. لا تخفِ المحتوى قبل التأكد من تشغيل المكوّن.
- كل حالة تفاعل واضحة: تحميل، فارغ، نجاح، خطأ، ورفض إذن. لا رسالة نجاح قبل تحقق النتيجة.
- مخطط البيانات خارج المنطق، ومكونات صغيرة بحدود مفهومة. لا مكتبة كبيرة لأثر يمكن تنفيذه ببساطة.
- لا تخزين بيانات شخصية أو مفاتيح خادم في الشيفرة. أمثلة الاتصال غير مفعّلة حتى يُحدَّد المستلم والخدمة والإذن.
- حماية الروابط الخارجية، وترميز مدخلات المستخدم وإظهارها بـtextContent. لا إدراج HTML غير موثوق.
- التحليل والإعلانات والتتبّع غير مفعّلة افتراضياً. الخصوصية بحسب الوظيفة الفعلية والبيانات المستخدمة.
- الموقع الطويل: تنقل فصول واضح، مصدر بجوار الادعاء، رابط عودة، وطباعة مدروسة إن كانت ضمن الوعد.
